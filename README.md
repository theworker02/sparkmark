# sparkmark

Spark CSV/TSV mark tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/sparkmark/

## Install / run

```bash
git clone https://github.com/theworker02/sparkmark.git
cd sparkmark
node src/cli.js
node --test
```
